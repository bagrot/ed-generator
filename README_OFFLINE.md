# Генератор пушей — локальная версия

Требуется Node.js LTS.

Запуск: двойной клик по `start.bat`.

Приложение откроется по адресу http://localhost:3000.

Шаблоны загружаются из `public/templates_rows.csv`. Авторизация, профили,
админка пользователей и подключение к Supabase в основном сценарии отключены.

Для обновления шаблонов замените CSV-файл новой выгрузкой с тем же именем.
